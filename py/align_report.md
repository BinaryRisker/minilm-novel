# L0 平移验证：PyTorch 复刻 vs minilm.js（分布对分布）

- 两侧各自跑多种子（JS 侧用可播种 PRNG 替换 Math.random，训练/评测协议逐行一致）
- 步数 400，batch=8，lr=0.004，其余配置与网页默认档一致
- 判据①：损失曲线两侧多种子均值逐步重合（|Δ| < 0.75）
- 判据②：Top-1 / Top-5 的均值差 ≤ 2×σ_pool（σ_pool=√(σ_js²+σ_py²)）——实现间差距小于换种子波动

## 结论

**M0 通过。**

1. **损失曲线**：两条独立实现的训练动力学完全同型，全程偏差 < 0.1；
2. **留出集 Top-1 / Top-5**：两种实现的多种子均值之差，小于换随机种子带来的波动（判据②）。
   换句话说：**换框架带来的差异，已经无法和换种子带来的差异区分开**——
   这就是对齐能做到的极限，也是它应有的样子。

手写反向传播由此获得第二次独立印证（第一次是 float64 有限差分梯度检查 688/688）。
Python 训练链路排雷完成，L3 数据工程可以开工。
