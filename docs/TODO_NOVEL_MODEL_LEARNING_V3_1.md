# V3.1 收口与优化清单

日期：2026-09-16。配套 [复核与设计](PRD_NOVEL_MODEL_LEARNING_V3_1_REVIEW.md)。本清单均待实施，不替代 V3 已完成的真实工作；随机初始化硬约束不变。

## 第一批：恢复与证据可信度

- [ ] `py/train.py`：恢复参数默认继承，exact resume 拒绝变更；显式新实验保留父谱系，meta 写实际配置。添加非默认 batch/lr 的 CLI 恢复反例。
- [ ] `py/checkpoint.py`：抽出完整状态、设备迁移、原子保存、损坏回退；中间快照也带完整身份。测试模拟写盘失败后旧文件仍可加载。
- [ ] `py/run_identity.py`：加入 bucket、实际内容/切片/顺序、tokenizer、代码、协议、有效参数；开训前计算，恢复比较。不同切片/不同桶身份必须变化。
- [ ] `py/splits.py`：验证实际正文与家族同 split，移除基于 processed_dir 的隐式免检；不可变分片清单复用验证结果。
- [ ] `py/sweep_worksplit.py`：模型/trigram 缓存校验完整签名与 schema；report_only 拒绝混合协议；原子临时文件名并发隔离。
- [ ] `py/locked_test.py`、训练与评测入口：开发不读 test；独立 final_eval、锁定版本、选中配置和访问台账；未曝光证明不能以重新冻结代替。
- [ ] sweep baseline_val/baseline_test 分开；图表断言目标位置一致；alpha 只在 val 选取，正式 test 不选参。

出口：本轮合成反例成为真正回归测试；发生漂移时必须拒绝，不能只告警后继续产生正式分数。旧协议结果可读但不会进入新验收汇总。

## 第二批：设备与最小训练闭环

- [ ] `py/novellm/doctor.py`：不消费全局 RNG、物理核不猜、精度字段区分算子与完整训练，补失败/缺依赖测试。
- [ ] `eval_ids/quick_eval` 正确迁移 tensor；检查点 CPU RNG 保持 CPU，CUDA/MPS 状态各自处理，恢复失败硬退出 exact resume。
- [ ] 正式训练 schema 拒绝 causal=False；消融入口明确标非生成模型并拒绝导出正式成绩。
- [ ] 按 V3 实现微型/30M、独立 EOS 等特殊 token、tokenizer、因果/缓存测试、离线导出，目标设备跑 train→val→save→resume→generate。
- [ ] GPU 上实测有效 token/s、峰值显存、分片读取吞吐与数值稳定；租卡只先给费用估算，不因本地 CPU 慢而直接租用。

## 第三批：数据与能力实验

- [ ] `py/data/prepare_stories.py` 与数据合同：冻结来源/用途/家族/分片，目标故事样本先人工抽审，再扩量。
- [ ] 新增曝光统计：unique token、总 token、每作品/簇曝光分位数、目标域比例、长度与题材；禁止只报字符总数。
- [ ] 固定 token 预算测试故事比例 25/50/75%，小试选择后再放大；固定词表比较同族 10M/30M，词表消融单独进行。
- [ ] 新颖度索引覆盖范围写入报告；全训练集长片段匹配或分片检索替代默认前 40 万字指标冒充全量。
- [ ] 开发题默认 val，续写与自主命题分开；增加题组 schema、空 prompt、非法解码参数、EOS、有效上下文及停止原因测试。
- [ ] 300–800 字阶段即真人完整阅读；正确计划/正确状态上限诊断单列，不混入正式自主成绩。
