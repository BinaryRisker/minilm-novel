# 结构消融：注意力头数 × 位置嵌入

> 日期：2026-09-13。实验文件：`py/ablation.py`。
> 原始数据：`py/runs/ablation_scifi_t20000_s800.json`、`py/runs/ablation_scifi_t2401_s800.json`。

## 1. 问题

1. 注意力头数（1 / 2 / 4 / 8）在固定参数量下，对留出集下一字预测有可测量的影响吗？
2. 把学习式绝对位置嵌入全部置零并冻结，模型会变差吗？

## 2. 假设

- 假设 A：更多头 = 更多种相似度度量，应带来更好的 Top-1。
- 假设 B：位置嵌入提供顺序信息，去掉后应明显变差。

## 3. 唯一变量

| 项目 | 值 | 是否固定 |
|---|---|---|
| 模型 | ctx=32 d=40 layers=2 ffMul=4 | 是 |
| 优化器 | Adam lr=0.004 + warmup/cosine + clip 1.0 | 是 |
| batch / steps | 8 / 800 | 是 |
| 测试集 | 全文最后 10% | 是 |
| 随机种子 | 42 / 7 / 1234（3 个） | 是 |
| **注意力头数** | **1 / 2 / 4 / 8** | **唯一变量** |
| **位置嵌入** | **学习式 / 置零冻结** | **唯一变量** |

关键点：**head 数不改变参数量**（Wq/Wk/Wv/Wo 都是 D×D），所以这不是「预算对比」，是「同一预算下如何切分子空间」的对比。

## 4. 两个语料设定

| 设定 | 语料 | 训练 | 留出 | V | 参数量 | 性质 |
|---|---|---|---:|---:|---:|---:|---|
| A 跨书本 | `corpus.json` scifi（13.2 万字，4 部清末作品拼接） | 前 20,000 字（《猫城记》开头） | 最后 10%（13,201 字，落在《新纪元》《电世界》） | 3,091 | 164,440 | **训练集与留出集来自不同作品**，含明显分布漂移 |
| B 同篇内 | `corpus.orig.json` scifi（2,668 字原创短篇） | 2,401 字 | 267 字（同一篇） | 365 | 55,400 | in-distribution，与历史实验同口径 |

## 5. 配置与命令

```bash
# A 跨书本
python py/ablation.py --corpus scifi --train_size 20000 --steps 800 \
  --seeds 42,7,1234 --heads 1,2,4,8

# B 同篇内
python py/ablation.py --corpus_file py/data/corpus.orig.json --corpus scifi \
  --train_size 2401 --steps 800 --seeds 42,7,1234 --heads 1,4
```

## 6. 结果

### 6.1 设定 A · 跨书本（trigram 基线 Top-1 = **7.5%**）

| 配置 | Top-1 均值 | std | Top-5 均值 | 训练末段 loss | 参数 | 对比 trigram |
|---|---:|---:|---:|---:|---:|---|
| h1 | 6.46% | 0.53 | 16.8% | 5.112 | 164,440 | 负 |
| h2 | 6.09% | 0.16 | 17.3% | 5.290 | 164,440 | 负 |
| h4 | 6.39% | 0.14 | 16.6% | 4.882 | 164,440 | 负 |
| h4_nopos | **6.99%** | 0.33 | 17.4% | **4.615** | 164,440 | 负 |
| h8 | 6.16% | 0.34 | 16.7% | 5.034 | 164,440 | 负 |

### 6.2 设定 B · 同篇内（trigram 基线 Top-1 = **39.5%**）

| 配置 | Top-1 均值 | std | Top-5 均值 | 训练末段 loss | 参数 | 对比 trigram |
|---|---:|---:|---:|---:|---:|---|
| h1 | 35.03% | 1.21 | 55.9% | 1.852 | 55,400 | 负 |
| h4 | 35.03% | 0.92 | 56.1% | 1.729 | 55,400 | 负 |
| h4_nopos | 33.98% | 1.94 | 55.9% | 1.710 | 55,400 | 负 |

## 7. 关键发现

1. **head 数 1/2/4/8 没有可区分的差异。** 跨书本设定下 Top-1 跨度 6.09%~6.46%，差值 ≤ 0.4pt，**小于或接近种子间 std（0.14~0.53）**；同篇内设定下 h1 与 h4 的均值完全相同（35.03%）。「更多头 = 更好」在本实验中没有出现。
2. **参数规模完全相同。** 两个设定的参数量在 head 1/2/4/8 下都逐位相同（164,440 / 55,400）。所以差异只能来自「子空间怎么切」，而这部分差异没有在这个规模上显现。
3. **位置嵌入置零没有明显变差，跨书本设定下甚至略好。** 同篇内（33.98% vs 35.03%）差 1.05pt，落在 ±1.2~1.9 的 std 内，无法与噪声区分；跨书本设定下 nopos 反而 +0.6pt（6.99% vs 6.39%），且训练 loss 更低（4.615 vs 4.882）。
4. **两个设定下模型仍全部输给 trigram**（35.0% vs 39.5%；6.4% vs 7.5%）。与数据量扫描的结论一致。
5. **h1 的训练 loss 最高**（同篇内 1.852 vs 1.729）。单头在拟合能力上确有代价，但这份代价没有体现在留出集 Top-1 上。

## 8. 失败样本 / 异常

- 设定 A 的 h4_nopos seed=7 单次 7.5%，与 trigram 打平；但其余两 seed 为 6.7%/6.8%——单次数字再次不可作为结论（见 L0 教训）。
- 设定 B 的 h4_nopos seed=7 只有 31.2%，是该组最低值，明显拉低均值。nopos 组 std 达 1.94，是 h4 组（0.92）的两倍。
- 设定 A 的留出集来自与训练集不同的作品（《猫城记》→《新纪元》《电世界》），存在分布漂移，因此绝对 Top-1 只有 6~7%。**该设定的数字不能与历史同篇内实验直接比较。**

## 9. 结论与边界

**结论**：
> 在 5.5 万~16.4 万参数、800 步、ctx=32 的范围内，注意力头数（1/2/4/8）与位置嵌入的存废，都对留出集 Top-1 没有超过种子波动的可测量影响。两者都不是当前模型的瓶颈。

**边界**：
> - 只有 3 个种子，std 由 3 点估计，只能给出「差异不显著」，不能给出「效应恰好为零」；
> - 仅 scifi 语料、固定 800 步、lr=0.004；
> - 设定 A 的 nopos 优势可能是「位置表过拟合训练作品」的一种表现，本实验无法区分这一点与噪声；
> - 未测 heads=8 在同篇内设定下的表现；
> - min_freq=1（保留全部字符），与 `sweep_data_scale.py` 新的默认 min_freq=3 不同。

**下一步**：
> 要真正判定位置嵌入的作用，需要一个更受控的设定：固定训练/留出为同一作品、把步数放大到模型接近收敛、种子数提到 ≥5。当前证据只能支持一句更弱的话——**在这个规模上，位置嵌入的收益没有超过噪声**。
