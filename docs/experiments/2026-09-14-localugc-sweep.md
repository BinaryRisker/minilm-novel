## 0. 这个桶是什么

只在**明确「个人本地学习」**的前提下启用（见 `docs/DATA_CANDIDATES.md` §五）。它**不在**
`sweep_worksplit.py` 的默认 `BUCKETS` 里，也**不参与**四个证据桶的横向排名——
它的数字只能自己跟自己比。

| 来源 | 入库 | 形态 |
|---|---|---|
| `liyucheng/zhihu_rlhf_3k`（GBK TSV） | 2,500 条 / 301 万字 | 知乎回答 |
| `liyucheng/zhihu_26k`（GBK TSV） | 2,500 条 / 644 万字 | 知乎回答 |
| `zirui3/zhihu_qa`（jsonl.gz） | 2,500 条 / 178 万字 | 知乎问答 |
| `next-social/zhihu_beautiful_super_alpaca`（JSON） | 2,500 条 / 161 万字 | 知乎精选 |
| `wdndev/webnovel-chinese`（首片前 30 MB，Range 流式） | 70 部 / 1,051 万字 | **网文小说** |
| `zhaoqixu/tianya-forum-scrapper` 的 `LXZ_chi(B).xml` | 2,907 帖 / 105 万字 | **天涯论坛对话** |

合计 **12,977 部 / 2,438 万字**；按作品切分后 train 10,381 部 / 1,765 万字池、test 1,299 部。
**真正的小说叙事只占 43%**（网文那 1,051 万字），知乎 53% 是问答体、天涯 4% 是辩论体。

| 训练字数 | 步数 | 模型 Top-1 | trigram Top-1 | 边距 | 模型 NLL | trigram NLL | 边距 |

## 2. 三条读法

1. **绝对值不可跨桶比**。`localugc` 的 Top-1 只有 4.5%，而 `wuxia` 是 13.6%——
   这不是"模型变笨"，是**语料熵高得多**：词表 V=8,404（`xiandai` 只有 2,894），
   内容来自上万个人的口语、网络用语、时评与跟帖。**只有"边距"这一列可以横向看。**
2. **2,000 字档 NLL 比 trigram 差 +0.94 nat，远比其他桶严重**（其余桶该档是 +0.10 ~ +0.81）。
   原因是协议性的：词表固定在**全部训练作品**上建（V=8,404），
   而 size=2,000 只给模型看 2,000 字 → 它要在 8,404 个候选上摊开概率，
   而 trigram 靠回溯到 unigram 就能把概率压在一小撮高频字上。**这是"大词表 + 极小数据"的惩罚，
   不是 UGC 语料的性质**。
3. **NLL 边距（−0.84 ~ −1.03）与公版桶同量级**，Top-1 边距 −0.5 ~ −0.8pt 也落在
   `gudian`(−1.73) / `urban`(+0.07) 之间 → **换成 UGC 语料，格局没有变化**：
   模型赢在整分布（NLL），输在峰值命中（Top-1）。这与 `xiandai` 桶的结论一致。

## 5. 可见样本：两次生成都退化（诚实记录）

给 `py/train.py` 加了 `--chars`（语料远大于步数预算时应缩语料而非无限加步数），然后跑两组：

| 组 | 语料 | 步数 | 结果 |
|---|---|---:|---|
| A | `localugc` 全量 781 万字 | 400（≈1% epoch） | **高频字汤**：`的的，是是是，不不我我` —— 连句子边界都没有 |
| B | `localugc` 前 20 万字 | 1,172（≈32 epoch，对齐续四的"够用预算"） | **对白碎片**：引号与"他/我们/人"的位置学对了，但字级重复崩塌（`他们们们`、`一个个个的`） |

B 组样例（输入 → 输出）：

```
入：为什么很多年轻人不愿意结婚了？
出：为什么很多年轻人不愿意结婚了？
    萧秋水，但在一个人，这个人。
    他的眼里来来，我们的一个孩们们们的的的人。
    “你要有一个人，“你有的的。他们们不会没有一种个个个女孩，他不不是自己的一个人。
```

```
入：我穿越到这个国家已经三天了，
出：……他他们在那些的的一样的人人，我的，那时去。他不会人，这个的一个人，
    只会会会是这一种的人了，我们在他他，我们们不不不能是一个人们们不有有有一人的，”
```

**读法**：A→B 改变的是**失败模式**，不是质量。B 组已经能稳定产出「引号包起来的对白 + 人称代词」
——这与语料里 43% 网文对白 + 53% 知乎口语吻合，说明模型学到的是**语域（register）**而不是句法。
字符级模型在这个预算下本来就处于 README 说的"背诵期"，而 UGC 的高熵（V=8,404）把崩塌放大了一档：
`localugc` 需要比公版小说**更多**的数据与步数才能出可读文本。

⚠️ **不要把 A/B 的指标当泛化成绩**：`train.py` 的留出是「同一片文本连续 90/10」（JS 对齐口径），
B 组报的 Top-1 86.2% / PPL 1.96 是**记忆**，不是泛化。泛化数字看 §1 的按作品留出。

产物：`py/runs/localugc_demo/checkpoint.pt`（A）、`py/runs/localugc_demo200k/checkpoint.pt`（B）、
`py/runs/story_eval_localugc_demo.json`、`py/runs/story_eval_localugc200k.json`。

## 6. 边界

- 固定 3 epoch → 20 万字档只有 586 步。**同日续四已证**：同档位把步数加到 1,172（12 epoch）
  能让 A 级三桶 Top-1 全部转正，所以**本表 −0.84pt 是"欠训练下的边距"，不能读成 UGC 语料的上限**。
- 桶内 **292 组内容重复**（842 部，知乎转载/相似短答所致）。`assign_splits` 按 hash 排序，
  同 hash 必落同一 split → 实测**跨 split 重复 0 组**，未引入泄漏，但语料被推向重复内容。
- 网文切片是**按字节截断**的：最后一部末尾被砍，且只覆盖首片 → 只见约 70 部。
- 天涯只取 ≥200 字的前 3,000 帖（实际入库 2,907），且**不是叙事文体**。
- **猫扑无源**：GitHub / HF 双向检索均无可核验数据集，未接入。
- 合规：**仅限个人本地学习**。`wdndev/webnovel-chinese` 的 Apache-2.0 标签不覆盖网文原作者权利，
  知乎/天涯内容是 UGC 著作权归发帖人。因此本桶**不可再分发、不可商用、不进评测与结论**。
