# 民国新文学公版语料：`xiandai` 桶数据量扫描

> 日期：2026-09-14。脚本：`py/sweep_worksplit.py --buckets xiandai --sizes 2000,10000,50000,200000 --tag xd`。
> 结果：`py/runs/wsplit_xiandai_*_xd_s*.json`、`py/runs/wsplit_summary_xiandai_xd_s42-1234-2024.json`、`py/runs/wsplit_report_xd.md`。

## 结论

`xiandai` 是许可干净的现代白话桶：35 部 / 110 万字，训练 split 28 部 / 36.2 万字，测试 split 4 部。按作品整篇切分、3 个种子、固定 3 epoch 后：

- **2 万字以上，模型 NLL 全部胜 trigram**（−0.60 ~ −0.90 nat）；2000 字档仍负（+0.13 nat）。
- **Top-1 全档落后**（−0.78 ~ −7.27pt）；200,000 字收窄至 −3.59pt，但没有翻盘。
- 这与 `gudian`/`wuxia`/`urban` 的总格局一致：模型先学到更好的完整分布（NLL），trigram 仍以记忆精确三字续接占 Top-1 优势。

## 语料与边界

- 来源为中文维基文库的公版民国白话：鲁迅短篇、老舍《骆驼祥子》《四世同堂》、郁达夫《沉沦》、萧红《呼兰河传》《生死场》。逐篇来源、许可、hash 见 `data/sources.json`。
- 清洗去掉每一维基页面顶部的相邻篇名、日期、编辑链接；否则导航会被误作正文训练。
- 训练池只有 361,755 字，故没有跑 1,000,000 字档；把 size 夹到池上限再标为「100 万」会制造伪数据量对照。
- 该桶文体为民国白话，不等于现代网文；它补的是「现代性更强 + 许可干净」，不是最终目标文风的替代品。
