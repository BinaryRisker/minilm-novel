# 内容选题表

> 按 PRD 六个选题方向编排。首篇建议「我发现模型没看懂我输入的字」。
> 标注 `【人工项】` 的内容必须由人类作者完成，不能由模型自动生成。

## 选题方向

1. **技术透明**：展示 OOV、token 映射、模型实际看到的输入。
2. **基线对照**：用 bigram/trigram 给模型成绩做及格线。
3. **数据实验**：回答「多少数据才能让模型超过 trigram」。
4. **对齐验证**：PyTorch 复刻与 JS 实现 bitwise 对齐。
5. **失败样本**：精选模型写砸的片段，说明局限。
6. **创作探索**：用模型辅助写作的实际尝试与人工修改。

## 内容产出原则

- 【人工项】标题、选题、叙事角度、失败样本挑选、结论边界，必须由人类作者决定。
- 模型可以辅助：生成初稿片段、整理实验数字、绘制图表、检查错别字。
- 发布前必须：明确标注模型版本、训练数据规模、评测指标、失败样本。
- 禁止：只选漂亮片段、隐瞒失败、把探索性结论说成通用结论。
