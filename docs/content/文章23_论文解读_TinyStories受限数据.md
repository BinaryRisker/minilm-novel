# 论文白话解读：TinyStories 为什么说「受限数据能教出连贯故事」

**系列：从零训练中文小说模型｜第 23 篇（研究论文白话解读）**

实验身份：无自研实验（论文白话解读）｜对照数据集=docs/DATA_CANDIDATES.md

按计划，每篇只讲一篇论文的一个观点，并明确分开「论文证明了什么」和「本项目还没验证什么」。

## 一、论文的问题

小模型到底能不能学会讲一个连贯的故事？如果能，需要多少参数、什么数据？

通行看法是「故事能力需要大模型」。TinyStories 这篇论文问的是相反方向：**如果数据足够简单、足够干净，小模型能不能学会？**

## 二、论文的结论（论文证明了什么）

论文构造了一批**词表受限**的短故事（用幼儿能理解的常用词写，篇幅短、情节简单），然后用不同规模的小模型（从百万参数级到数千万参数级）训练。结论是：

- 在这些受限数据上，**很小的模型就能生成语法正确、逻辑连贯、有开头和结尾的短故事**；
- 关键变量是**数据的简单与语法干净**，而不是单纯堆规模；
- 用同样的模型去训更「自然」但更杂乱的数据，反而更难学会连贯。

一句话概括：**数据的形式限制了模型能学到什么。** 简单、干净、边界清晰的语料，能把「学说话」和「学组织情节」这两件事分开。

## 三、对 MiniLM Lab 的可检验实验（我们还没验证的）

这篇论文对我们最有用的地方，是它给出了一个可以证伪的方向，而**不是**可以直接抄的结论：

1. **受限词表实验**：把同一批原创语料改用高频字表重写（例如只保留最高频的 500~800 字），其余用有限词汇替代，固定模型与步数重训，比较留出集 Top-1 与生成质量。若 TinyStories 的结论在中文、在我们的规模上成立，受限版应更连贯。
2. **合成语料对照**：`docs/DATA_CANDIDATES.md` 里记录过 `TinyStoriesChinese`（约 2.6 GB，TinyStories 全量中文译文，CDLA-Sharing-1.0）。它是许可干净、故事边界清晰的合成数据——正好补上我们目前最缺的「现代文风 + 许可干净」那一格。可以拿它训一个小模型，和我们的原创语料做同配置对照。
3. **要警惕的差异**：论文的规模是百万到数千万参数、数据量远超我们。我们的语料只有千字级、模型 55,400 参数，**在这个预算下 TinyStories 的结论是否成立，我们没有任何证据**。这也正是它值得做实验的地方。

## 四、结论边界
## 三·补、一张对照表

| 维度 | 论文证明了什么 | 本项目还没验证什么 |
|---|---|---|
| 语言 | 英文 | 中文是否同样成立 |
| 词表 | 受限（幼儿常用词） | 我们没做过受限词表实验 |
| 模型规模 | 小模型（百万~数千万参数） | 我们只有 5.5 万参数 |
| 数据量 | 远大于本项目语料 | 我们最多到万字级 |
| 评测 | 连贯性人工评估 | 我们的留出集 Top-1 还赢不了 trigram |


- 论文结论建立在**英文、受控词表、合成/简化数据**上；中文是否存在等价的「简单又干净」的语料，是一个未解决的问题（见数据候选报告：规模、许可、故事边界三条件目前无交集）。
- 「受限数据能帮助小模型」**不等于**「把词汇砍一半模型就会变好」。它更可能是一条提示：**训练的难度应该与模型的容量匹配**，而不是一味追求「更像真实世界的语料」。
