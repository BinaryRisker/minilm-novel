# 误差怎样变成更新：反向传播与优化器

**系列：从零训练中文小说模型｜第 8 篇（原理篇）**
**前置阅读：原理篇 7；不熟悉的术语可回阅读地图查询**

更新：2026-09-17。本文先讲通用原理，再说明本项目怎样实现；算例均标明用途。

有了 loss，程序还需要知道几万个甚至几十亿个参数该怎样修改。反向传播和优化器分工合作：前者计算梯度，后者决定更新。

梯度表示“在当前参数附近，某个参数发生微小变化时，损失怎样变化”。它是局部敏感度，不是道德上的责任分配，也不是对复杂因果关系的完整解释。

## 先看一个只有一个参数的例子

令 `loss=(w-3)^2`。w=1 时，loss=4，梯度是 `2×(1-3)=-4`。使用学习率 0.1 的普通梯度下降：

```text
新 w = 旧 w - 学习率 × 梯度
     = 1 - 0.1 × (-4) = 1.4
新 loss = (1.4-3)^2 = 2.56
```

这次确实下降了。神经网络的反向传播用链式法则高效计算所有参数的梯度，不需要逐个参数扰动重算整张网络。

但是反向传播本身不更新参数，也不保证每一步的损失下降。步长过大、批次不同、浮点误差或优化器状态都可能让某一步上升；训练通常观察一段时间的趋势。

## 真正训练循环长什么样

下面是解释顺序的 PyTorch 示意，不能脱离模型和数据单独运行：

```python
optimizer.zero_grad()           # 清掉上一次梯度
logits, loss = model(x, y)      # 前向计算和损失
loss.backward()                # 计算梯度
optimizer.step()               # 按梯度和优化器状态更新参数
```

梯度默认可以累加，所以要清零。梯度累积训练则故意跨几个小批累计，正确缩放损失后再更新，以较小的单批显存实现较大的有效 batch。它不保证与一次大批计算逐位相同。

## Adam 记了什么

本项目使用 Adam。它维护梯度的指数滑动平均 m，以及梯度平方的指数滑动平均 v，并做偏差校正。第二个是二阶原点矩，不能简单说成“梯度幅度平均”或“方差”。更新大致用 m 除以 v 的平方根来调整各参数步幅。

所以 Adam 需要额外状态，恢复训练时也必须保存。学习率预热逐渐提高初期步长；余弦调度让步长随计划变化；梯度裁剪限制过大的梯度范数。这些都是稳定训练的工具，不是用了就不会发散的保证。

项目旧教学学习率 0.004 是某套配置的工作值，不应原样当作任意大模型的推荐值。遇到异常，要一起检查数据、数值精度、梯度和优化配置。
