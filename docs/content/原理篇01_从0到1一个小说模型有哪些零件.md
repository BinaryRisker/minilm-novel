# 从一句话开始：大模型究竟怎样学会接着写

**系列：从零训练中文小说模型｜第 1 篇（原理篇）**
**前置阅读：无，从这里开始**

更新：2026-09-17。本文先讲通用原理，再说明本项目怎样实现；算例均标明用途。

给程序一句“小雨把笔记还给了”，它怎样接出“失主”？可以先把语言模型理解成一台会根据前文给后续文字打分的机器。训练的任务，是让它在大量例子上把原文接下来的文字预测得更好。

这里的“大模型”通常有很多可学习数字，叫参数。我们先用同类原理的小模型做实验：计算过程容易看清，普通电脑也能参与。学会小模型的训练流程，不代表只要按比例放大就能复制成熟大模型的能力。

## 先区分三样东西

| 名称 | 它是什么 | 例子 |
|---|---|---|
| 模型结构 | 数字怎样参与计算的规则 | Transformer 的层数、宽度、注意力 |
| 参数或权重 | 训练会修改的数字 | 嵌入表、矩阵里的数 |
| 训练数据 | 用来出练习题的文本 | 一批完整、清洗过的故事 |

“从零训练”指参数从随机初始化开始，没有加载别人已经训练好的权重。使用 PyTorch 自动求导仍然是从零训练。给已有模型发提示词通常不改权重；微调则从已有权重出发继续训练。本项目采用随机初始化路线。

## 一句话怎样变成练习题

用字符级分词举例，原文是“小雨回家了”。把两行错开一格：

```text
输入：小 雨 回 家
答案：雨 回 家 了
```

在“小”的位置预测“雨”；到“回”的位置，可根据“小雨回”预测“家”。训练程序已有原文，因此不需要人给每个字另写标签，这叫自监督学习。一次计算能同时给多个位置出题，但每个位置都要遮住右边的答案。

## 一次训练，只有四件核心事

1. 前向计算：输入变成编号和向量，经过模型，得到下一 token 的分数。
2. 算损失：检查模型给正确答案多少概率，用一个数概括预测误差。
3. 反向传播：计算每个参数对损失的局部影响，得到梯度。
4. 优化器更新：根据梯度小幅修改参数，再取下一批练习。

最初的参数不知道中文；反复练习后，它可能学会常见字词、句法及更长的关系，也可能记住训练片段。究竟学到了什么，必须用未用于训练的数据检查。

## 写作时有什么不同

生成时没有原文答案。模型先为下一 token 打分，按规则选一个，把它接回前文，再预测下一个。通常不再更新参数。若它写错了人物名字，后续还会读到自己写错的文字，因此局部接得顺并不保证整篇故事连贯。

现代语言模型还可能经历指令微调、偏好优化等后续阶段；它们让模型更适应任务和人的要求。基础预训练、后续训练和应用里的检索/规划应分别理解。本项目还没有完成这些阶段的全部实现和能力验收。

## 这套课程怎么走

先读 2–6 篇，弄清文字如何变成预测；再读 7–10 篇，理解训练怎样更新与保存；第 11 篇讲如何判断进步。然后按[阅读地图](README.md)亲手训练一次。暂时不必背模型配置和历史成绩表。
