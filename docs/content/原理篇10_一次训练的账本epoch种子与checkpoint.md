# 一次完整训练的四本账：epoch、种子、过拟合与 checkpoint

**系列：从零训练中文小说模型｜第 10 篇（原理篇）**
**前置阅读：原理篇 1（全景）、原理篇 8（反向传播与优化器）**

实验身份：model=MiniLM-char-v1｜epoch=3（固定）｜seeds=1234,42,2024｜batch=8｜checkpoint=`py/train.py` 只存 model/itos/meta

前面的原理篇都在讲「一步训练」。真实训练是几十万步的长跑，长跑最容易丢的不是步频，是**账**——跑完说不清「我训练的到底是什么」。本篇把账本立齐：四本都要记。

## 账本一：epoch 与 batch

**epoch** = 全部语料完整过一遍。本项目固定 3 epoch，相当于全集读三遍：读少了没记住，读多了开始背。**batch** = 不逐字改参数，攒一小撮（batch=8）算平均责任再统一拧旋钮——又快又稳，单字的噪声互相抵消。顺带说「固定 epoch」的用意：对照实验要控制变量，大家都读三遍再比成绩，「多读几遍」才不会冒充「更聪明」——这是实践篇对照组的基本礼仪。

## 账本二：种子

初始化、数据洗牌，全都听**随机种子**的号令。换种子 = 平行宇宙里重训了一个模型——结构、数据、步数全同，成绩照样抖。抖多大？实践篇第 8 篇的答案很颠覆直觉：**看数据量档**。

| 训练字数档 | Top-1 种子 σ |
|---|---|
| 2,000 字档 | ±0.2~1.5pt |
| 1,000,000 字档 | ±0.1pt（1pt ≈ 10σ） |

小数据档里 1pt 的「提升」可能纯属抽样运气——有一次 24.0% 的成绩落在均值 4σ 之外，就是典型的一次幸运抽样；到了百万字档，1pt 是实打实的 10σ 巨差。「三个种子够不够」因此没有标准答案，答案随档位变（实践篇第 8 篇）。

## 账本三：过拟合

**过拟合** = 把训练题背下来了，而不是学会了。侦察信号是**两本账分裂**：训练 loss 一路走低、留出集 NLL 却不降反升。本项目早期就撞上过：训练 loss 1.3~1.6 的模型，留出 NLL 3.5~5.7（旧口径时期数字，量级示意；实践篇第 10 篇）。一个密度视角很提神：5.5 万参数喂 2,000 字 ≈ **29 个参数伺候一个字**——这个密度下模型的理性策略是背，不是学（实践篇第 10、17 篇）。

## 账本四：checkpoint

**checkpoint** = 训练中途的存档。存什么？答案不是「权重」两个字，是「**重启训练需要的一切**」。实践篇第 28 篇盘点过本项目的存档内容：

| 重启真正需要 | 是否保存 | 不保存的后果 |
|---|---|---|
| 权重 model | ✅ | — |
| 词表 itos | ✅ | 没它权重就是一堆乱码 |
| 配置与进度 meta | ✅ | 不知训到哪 |
| **Adam 的 m + v 两本账** | ❌ | 重启等于换优化器，前几十步全是重新适应 |

那两本账有多大？约 2.25 MB，差不多是权重的**两倍**——「保存了模型」和「保存了训练状态」之间，差的就是它们。

## 边界

- 3 epoch、固定步数是**算力预算下的选择**，不是收敛证明（训练末段 loss 仍在 1.7+）；
- 种子结论依赖档位，跨档引用数字必须带上档位标签。

**在哪里亲眼看**：`index.html` 训练曲线（loss 走势）；「训练控制」换个 seed 重训，亲眼看看平行宇宙。
