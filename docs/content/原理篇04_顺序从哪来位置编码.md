# 「我先说」和「说我」不是一回事：位置编码

**系列：从零训练中文小说模型｜第 4 篇（原理篇）**
**前置阅读：原理篇 1（全景）、原理篇 2（词表）、原理篇 3（embedding）**

实验身份：model=MiniLM-char-v1｜cfg=ctx=32 d=40 layers=2｜位置表=学习式绝对位置 32×40（1,280 参数）｜对照=2026-09-13 ablation（`py/ablation.py`）

原理篇 3 给每个字发了一张档案卡。现在有个尴尬的问题：把「我打他」和「他打我」交给模型，两张卡的**组合一模一样**——卡上只写「这是什么字」，没写「谁排在谁前面」。而注意力本身也不认识顺序。换句话说，不补一张座位票，模型眼里这两句是**同一句**。先递刀再握手是江湖，先握手再递刀是刑侦剧，这事不能含糊。

## 座位号牌：进门前顺手一加

解法朴素：每个字进模型时，除了档案卡，再领一张**座位号牌**（位置编码，也是 40 个数），两张相加：

```js
x[i * D + d] = P.emb[tok * D + d] + P.pos[tp + d];   // minilm.js
```

注意座位号是「这个字在本窗口里排第几」，不是字的编号。本项目用**学习式绝对位置**：位置表不是公式算出来的，是一张 32 行 × 40 列的参数表，跟档案卡一样靠训练改。三种流派：

| 方案 | 怎么来 | 本项目 |
|---|---|---|
| 学习式绝对位置 | 每个座位一张可训练的牌 | **在用** |
| 正弦位置编码 | sin/cos 公式直接算，不训练 | 未用 |
| RoPE 旋转位置 | 在 q/k 上旋转，带相对位置性质 | 未用 |

它有张倔脾气：**只有 32 排座位（ctx=32），第 33 个字进场没牌。** 所以想加长上下文不能只把 ctx 滑条拧到 64——后 32 张牌从没被训练过，等于发空白票。改 ctx 必须重训（实践篇第 21 篇）。

顺带回答一个常见疑问：为什么两张牌**相加**而不是拼接？拼接会让每层输入从 40 维涨到 80 维，全模型的参数和算力跟着翻倍；相加保持 40 维不变，代价是「身份」和「座位」两路信号挤在同一段电波里互相干扰——后来 RoPE 等新方案想缓解的正是这个紧张。小模型先选便宜的，很合理。

## 我们真把座位票废掉过

把位置表全部置零并冻结，其他不动，重训（3 种子，800 步）：

| 设定 | Top-1 有位置 | Top-1 置零 | 训练 loss 有/置零 |
|---|---:|---:|---|
| 同篇内（2,668 字） | 35.03% | 33.98%（σ 0.9~1.9） | 1.729 / 1.710 |
| 跨书本（13.2 万字） | 6.39% | **6.99%** | 4.882 / 4.615 |

读法：同篇内掉 1.05pt，但落在种子波动里；跨书本反而高了 0.6pt；两个设定下废票后训练 loss **都更低**。所以在「5.5 万参数 + 32 上下文」这个规模上，位置票的收益**没跑赢噪声**（实践篇第 21 篇）。

## 边界

- 「收益不显著」≠「位置编码没用」——只有 3 个种子、模型远未收敛，「没有顺序信号就只剩一袋字」这件事并没有消失，只是没被测出来；
- 但反过来也成立：**「位置编码当然有用」从今天起不能再当免检前提**，它在本项目是要做实验才能主张的。
- 顺带两个名词（后篇直接用）：残差——每层算完把原文加回来，改卷不撕原卷；LayerNorm——每层开工前把向量「音量」归一，防止越算越跑偏。原理篇 5 会见到它们。

**在哪里亲眼看**：`index.html`「模型结构」表里 emb / pos 两行的参数规模（201×40 与 32×40）。
