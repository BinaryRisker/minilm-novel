# 它写了一段很美的废话：我的小模型失败样本

**系列：从零训练中文小说模型｜第 6 篇**

实验身份：model=MiniLM-char-v1｜corpus=三语料｜seed=42(单次)｜steps=400｜protocol=统一协议(eval/protocol.js)

模型最会骗人的时候，不是输出乱码，而是输出一段语气正确、画面漂亮、但事情没有发生的文字。

在武侠语料上，模型能稳定生成“雨、灯、剑、青石板、肩膀”这些意象，也能模仿“他说”“她看着”“女子问”的对话节奏。读第一眼时，它很像一段武侠小说。

但继续读下去，问题就出现了：
一段完整样本（武侠语料，温度 0.8，提示词「沈砚站在」，80 字，未删改）：

> 沈砚站在她们打了三息来，很快就为什么。  她扶起来。 伙计说，那个人一盏笼，很快就上去。她说，楼的伙计，是故意的肩膀的时候，一道白色上去。  雨照成一本剑谱。她说，楼里

「一盏笼」「雨照成一本剑谱」单看都有画面。但读完整段：谁在打、为什么停、剑谱发生了什么，全部没有答案。
人物没有明确目标，动作没有因果，上一句说要拔剑，下一句又回到灯笼和雨。它知道这个题材应该使用哪些词，却不知道这些词应该如何共同推动一场戏。

这也是为什么我现在不再把“风格像”写成“会写小说”。风格词汇、标点节奏和短距离句法只是第一层能力；人物一致性、事件完成和结尾收束，才是故事能力。

目前的评测会把这些问题拆开：下一字预测看语言规律，重复率看采样多样性，最长公共子串看是否复读，人物事实和事件完成度则需要单独的故事评测。不同指标不能互相冒充。

接下来我会给模型输入结构化的大纲和人物卡，只要求它写一个 300～800 字的场景。每个场景包含人物、地点、目标、冲突和结果，再比较“直接续写”和“先计划再写”。

如果结构化输入仍然不能让模型完成一场戏，我会把失败归因到数据和模型能力，而不是继续堆提示词。公开失败样本的意义，就是让读者看到一个语言模型从“会说话”到“会讲故事”之间还隔着多远。

## 这个失败更可能来自哪里

先把「像小说」拆成几层，再看每一层由哪个指标负责——不拆开就会把它们混成一件事：

| 能力层 | 用哪个指标看 | 当前状态 |
|---|---|---|
| 用词与标点像中文 | 留出集 Top-1 / NLL | 做到了 |
| 短距离句法成立 | 4-gram 重复率、distinct-2 | 基本做到 |
| 没有照搬训练集 | 8-gram 重合率、最长公共子串 | 做到了（0%~0.5%） |
| 人物保持一致 | 场景级人工评测 | **没做** |
| 事件真的推进 | 场景级人工评测 | **没做** |
| 结尾收束 | 场景级人工评测 | **没做** |

前三行是「语言」，后三行是「故事」。模型过了前三关、后三关一次都没测——这就是为什么「很美的废话」这个失败，更可能来自**评测和训练目标**，而不是解码或语料。
