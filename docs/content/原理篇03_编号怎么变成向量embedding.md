# 一个编号怎样变成可学习的向量

**系列：从零训练中文小说模型｜第 3 篇（原理篇）**
**前置阅读：原理篇 2；不熟悉的术语可回阅读地图查询**

更新：2026-09-17。本文先讲通用原理，再说明本项目怎样实现；算例均标明用途。

“雨”的编号是 2，模型接下来会按编号从一张表取出一行数字。这行数字叫向量，这张可学习的表叫 embedding（嵌入表）。它把离散的符号变成后面可以连续计算的表示。

假设用 3 个数表示一个 token，下面只是示意，不是真实模型权重：

```text
“小” → [ 0.2, -0.1,  0.4]
“雨” → [-0.3,  0.5,  0.1]
```

这些数起初随机生成，训练时会改变。不能随意给其中一格命名为“天气”、另一格命名为“人物”：模型并没有被规定用这样的方式储存意义。向量是否承载某种关系，需要实验分析。

## 宽度是什么

每行有多少个数，叫表示宽度，代码里常写 `d`。教学模型的一套配置是 `d=40`，意思是每个位置用 40 个数表示。宽度更大通常增加容量和计算开销，但不保证在相同数据和预算下更好。

词表有 V 个 token，表宽为 d，则嵌入表有 `V×d` 个参数。比如 V=201、d=40，共 8040 个数。每个 token 有独立的一行；宽度小不等于两个 token 被强制塞进同一行。

## 输入表示会随上下文变化

查表得到的是初始表示。同一个“雨”先取到同一行，但在“下雨”和“小雨回家”中，经过后续注意力和前馈层后，表示可以不同。理解这点，才能区分“一个字的固定嵌入”和“这个位置经过上下文处理后的表示”。

本项目输出打分还复用嵌入表，叫权重共享：最后的表示与每一行做点积，得到各 token 的分数。它省去一套独立输出矩阵；这不是普通的字典反查，也不保证分数最高的就是语义最接近的词。

## 为什么旧文章的参数量不一样

固定 `ctx=32,d=40,layers=2,ffMul=4` 的旧配置，参数公式为 `40800+V×40`。因此 V=201 时是 48840，V=365 时是 55400，不能把两者写成同一个实验。

这个常数只适用于这套配置。改变层数、宽度、上下文，主体参数也会变；当前 t30m 候选也不能套用它。查看运行 metadata 中的实际参数量，比看模型昵称可靠。
