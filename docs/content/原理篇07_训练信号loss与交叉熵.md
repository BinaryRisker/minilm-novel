# 猜错要挨罚，自信地猜错罚最重：loss 与交叉熵

**系列：从零训练中文小说模型｜第 7 篇（原理篇）**
**前置阅读：原理篇 1（全景）、原理篇 6（logits 与 softmax）**

实验身份：model=MiniLM-char-v1｜corpus=记忆之海(2,668字)｜算例 trace=「苏念说，我」｜本篇算式与数字引自实践篇第 22 篇

模型交上来一整张概率表（6,379 个字），标准答案只有一个字。训练要问的是：**这一注押得怎么样？** 把「整张表 + 正确答案」折成一个数字的公式，就是**交叉熵**；折出来的数就是 **loss**——训练全程拼命想压小的那个数。

公式看着唬人，意思很直白：

```text
loss = − log( 你给正确那个字留了多少概率 )
```

只看你对正确答案够不够大方，别的字一概不问。为什么套一层对数？因为概率直接连乘会小到计算机都存不下（几百个 0.2 相乘≈小数点后三百位），取对数把连乘变连加，账本记得起；顺便把「罚金」拉开档次——这正是下面三个算例的主题。想要一条瞎蒙基准线也有：二选一乱猜、猜对的概率 0.5，loss 就是 −ln(0.5)≈0.69——比它高说明练了还不如猜。

## 三个算例，罚出三种人生

用实践篇第 22 篇记录的真实 trace（提示词「苏念说，我」）：

| 场景 | 给正确字的概率 | loss = −ln(p) | 评语 |
|---|---:|---:|---|
| 笃定且对（⏎ 78.4%） | 0.784 | ≈ 0.24 | 几乎免罚 |
| 摇摆着对（不 29.7%） | 0.297 | ≈ 1.21 | 犹豫有价 |
| 自信地猜错（押 A 0.99，答案 B） | ≤ 0.01 | ≥ 4.6，可上 10 | 对数尺度重罚 |

**对数是这场考试的狠角色**：概率从 0.8 掉到 0.3，罚金从 0.2 涨到 1.2；掉到 0.01，罚金直接 4.6 起步。所以「自信地猜错」不是普通的错，是被指数放大过的错。模型也很快悟出最省事的策略——**没把握时别把宝全押一处**：候选分布面板上那些「四个字各 20%」的犹豫，不是它怂，是被这么罚出来的生存智慧。

## 反向传播时它就一行

softmax 加交叉熵，求导化简后只剩：

```js
dlogits = probs − onehot   // 预测分布 − 正确答案
```

「你给的」减去「该给的」：猜得越离谱，差值越大，原理篇 8 的那只手就推得越狠。

## loss 数值怎么读

取 e^(−loss) 就翻译回人话——「模型给正确字的典型概率」。训练日志里 loss 1.46，意思是正确字的典型概率尺度约 23%。听着不高？对了，这才第三百多步，而且这是**训练题**的自评。

两本账要分清（旧口径时期的数字，量级示意，口径说明见实践篇第 22 篇）：训练 loss 1.63 的模型，换到没见过的留出题上 NLL 3.52；训练 1.34、留出 5.65。换算成概率：训练时给 26%，考场只剩 0.3%。**同一个公式，两个模型**——一个在背书，一个在预测。

## 边界

- 交叉熵只评价**概率**，不评价句子通不通、故事好不好——把训练集背下来的模型也能把 loss 压到 1.3 以下，同时写出「一盏着」这种缝合（实践篇第 5、11 篇）；
- loss 低只是「把优化的那份卷子做熟了」，不含任何泛化承诺。
