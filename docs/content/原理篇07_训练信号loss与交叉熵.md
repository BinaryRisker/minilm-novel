# loss 怎样告诉模型哪里预测得不好

**系列：从零训练中文小说模型｜第 7 篇（原理篇）**
**前置阅读：原理篇 6；不熟悉的术语可回阅读地图查询**

更新：2026-09-17。本文先讲通用原理，再说明本项目怎样实现；算例均标明用途。

训练原文为“小雨回家”，当前前文是“小雨回”，答案就是“家”。模型可能认为“家”“校”“店”都说得通，但这道训练题要提高原文“家”的概率。

交叉熵损失在单个正确标签的情形下很简单：

```text
loss = -ln(分配给正确 token 的概率)
```

这里 ln 是自然对数。下面是教学算例，与项目某次训练成绩无关：

| 给“家”的概率 | loss（约） | 含义 |
|---|---:|---|
| 0.8 | 0.223 | 给正确答案较高概率 |
| 0.2 | 1.609 | 还不够确定 |
| 0.01 | 4.605 | 几乎排除了正确答案，惩罚较大 |

这就是“自信猜错”损失大的原因。正确概率很小但不为零，仍然可以被重罚。另一方面，有限数据中的每道题只有一个参考答案，不代表自然语言只能有一种合理续写。

## 一批题怎么变成一条曲线

通常对有效目标位置的损失求平均。若某些位置是补齐长度的 padding，或任务设计要求不计入损失，就应遮掉这些位置。日志里的平均值还可能是最近若干批的平均，要看具体实现。

如果平均损失为 L，`exp(-L)` 是这些位置正确 token 概率的几何平均，不能当成 Top-1 准确率。`exp(L)` 叫困惑度，是另一种表达损失的方式；它不是模型真的只在这么多个字中选择。

## 有没有“低于多少就学会”的线

没有通用的 loss 及格线。V 类均匀分布的损失是 `ln(V)`，不是固定 0.69；0.69 只对应二分类均匀基线。即使低于均匀基线，也应和按字频、trigram 等更有意义的基线比较。

更不能把不同 tokenizer 的每 token 损失直接排榜：token 的粒度变了，一道题有多难也变了。跨方案比较需要统一文本、计量方式和评测任务。

## loss 低，为什么还会写不好

训练 loss 低，说明更适应训练题；验证 loss 改善，才为未见数据上的预测提供证据。两者都不能代替完整故事阅读。人物是否前后一致、事情有没有结果，仍要单独检查。

但也不要反过来说“预测下一个 token 就不可能学到规划”。长程关系可以帮助预测，它可能被模型学习；本项目失败样本不能证明训练目标在原理上无法支持故事能力。
