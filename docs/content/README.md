## 第二轮：亲手做一次

读[第一次训练](第一次训练_从浏览器到Python.md)：先用浏览器，再用 CPU 训练 40 步、保存、恢复到 80 步、查看完整生成。先以“能解释每步做了什么”为目标，不以第一份小说好看为目标。

然后读[长篇入门指南](../NOVEL_MODEL_FROM_ZERO_BEGINNER_GUIDE.md)，了解数据、硬件和后续阶段；扩大训练前用[现行训练手册](../FORMAL_30M_SCRATCH_TRAINING_RUNBOOK.md)。
