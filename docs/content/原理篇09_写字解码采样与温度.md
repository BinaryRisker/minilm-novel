# 模型怎样一个 token 接一个 token 地写下去

**系列：从零训练中文小说模型｜第 9 篇（原理篇）**
**前置阅读：原理篇 8；不熟悉的术语可回阅读地图查询**

更新：2026-09-17。本文先讲通用原理，再说明本项目怎样实现；算例均标明用途。

训练结束后，权重已经固定。生成时反复做：读当前前文、给下一 token 打分、选一个 token、接回前文。这个选择过程叫解码。

假设下一步三个候选的概率是“家”0.6、“校”0.3、“店”0.1。贪婪解码每次选“家”；随机采样按概率抽取，因此偶尔会选“校”或“店”。下面各规则改变的是如何选择，不是把权重重新训练一遍。

| 规则 | 做什么 | 应注意什么 |
|---|---|---|
| 贪婪 | 每步选最高分 | 局部最高不等于整段最优，也可能循环 |
| 温度 T | 将 logits 除以正数 T | 小于 1 更集中，大于 1 更平缓 |
| top-k | 只保留得分前 k 个再采样 | 可能过滤噪声，也可能排除合理候选 |
| top-p | 保留累计概率达到阈值的候选集合 | 通用概念，当前主生成路径未实现 |
| 重复惩罚 | 降低某些已出现 token 的分数 | 也可能伤及应重复的人名、虚词 |

温度 T>0 不改变原始排名，所以只调温度不能提高同一 logits 的贪婪 Top-1；它改变的是采样概率。T=0 通常是接口中表示贪婪的约定，不能直接拿来除 logits。

## 为什么同一提示词会写出不同文本

采样使用随机数。固定模型、提示词、解码参数和采样种子，并控制运行环境，才更容易复现输出。训练种子决定初始权重和训练抽样，采样种子决定生成选择，两者要分开记录。

比较模型时可先用统一的采样规则做对照；也可以分别在验证集调解码参数，但应披露调参预算与规则，最后再盲测。不能从很多次输出中挑最好的一次，却说它代表稳定表现。

## 连续写很多字，就能写长篇吗

不一定。窗口之外的历史可能已经被丢弃；即使仍在窗口内，模型也未必学会使用。循环生成只是机械能力，人物一致、事件因果、结局完成需要额外评估。

过低温度可能放大模型已有的重复倾向，过高温度可能抽到不合适的词，但这些不是必然规律。合适的温度也不能凭空补上没学好的语言规律。输出差时，数据、预算、模型和解码都值得排查，不能仅凭“参数在常见范围”就排除采样影响。

动手时，固定一个开头，在每个温度下保留三段完整文本。分别标注重复、断句、人物和事件；你会看到“多样”和“连贯”是不同维度。
