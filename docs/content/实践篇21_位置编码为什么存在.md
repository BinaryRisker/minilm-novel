# 位置编码为什么存在？

**系列：从零训练中文小说模型｜第 21 篇（实践篇·模型拆解课）**
**前置阅读：原理篇 4（顺序从哪来：位置编码）**

实验身份：model=MiniLM-char-v1｜cfg=ctx=32 d=40 layers=2｜seeds=42,7,1234｜steps=800｜A=跨书本 B=同篇内；pos 置零并冻结

如果只看无位置的自注意力计算，它本身没有“这是第几个字”的内在标记；同一组 token 的顺序信息不能凭空出现。因果 mask 仍然会限制每个位置只能看前缀，所以不能简单说模型完全看到了“一袋字”，但它缺少表达精确顺序的信号。

**没有位置信息，模型很难区分同一组字的不同排列。** 位置编码就是为此存在的。

## 这个项目怎么做的

`minilm.js` 前向的第一步只有一行：

```js
x[i * D + d] = P.emb[tok * D + d] + P.pos[tp + d];
```

其中关键在 `tp = (i % T) * D`——取的是「这个字在本窗口里的第几个位置」，不是字的编号。做法是**学习式绝对位置嵌入**：一张 32 × 40 的表（ctx=32、d=40，共 1,280 个参数），和词嵌入一样是训练出来的参数，第 598 行能看到它的梯度回流。

## 三种位置的差别

| 方案 | 怎么来 | 本项目是否使用 |
|---|---|---|
| 学习式绝对位置 | 每个位置一张可训练向量 | **使用** |
| 正弦位置编码 | 用 sin/cos 公式直接算出，不训练 | 未使用 |
| RoPE 旋转位置 | 在 q/k 上做旋转，带相对位置性质 | 未使用 |

所以我们的位置表是**参数**，不是公式。代价很直接：**它只有 32 行，第 33 个字没有位置可用。**

## 一个立刻能验证的后果

训练时 ctx=32，位置表就只有 32 行。想让模型处理更长的上文，不能只把 ctx 改成 64——那样位置表的后 32 行从未被训练过，等于给它随机噪声。

这解释了实验台里一个容易被忽略的事实：`index.html` 的 ctx 滑条改完是**必须重新训练**的，不能训完再调。也解释了为什么「长上下文」不是把小模型的方向盘拧一下就能拿到的东西。

## 我们真把位置表关掉了（2026-09-13 补测）

把 `P.pos` 全部置零并冻结（`requires_grad=False`），其他一切不变，重训。固定 ctx=32、d=40、2 层、4 头、800 步、3 个种子：

| 设定 | 配置 | Top-1 均值 | std | 训练末段 loss |
|---|---|---:|---:|---:|
| 同篇内（2,668 字原创短篇） | 有位置 | 35.03% | 0.92 | 1.729 |
| | **位置置零** | 33.98% | 1.94 | **1.710** |
| 跨书本（13.2 万公版合集） | 有位置 | 6.39% | 0.14 | 4.882 |
| | **位置置零** | **6.99%** | 0.33 | **4.615** |

读法：

- **同篇内掉了 1.05pt，但落在 ±1.2~1.9 的种子波动里**，无法与噪声区分；
- **跨书本设定下反而高了 0.6pt**；
- 两个设定下，关掉位置表后的训练 loss **都更低**。

所以在这个规模上，位置嵌入的收益**没有超过这次实验的噪声**。一个可能解释是位置表的部分容量被用于记住训练作品的位置结构，但这需要更严格的实验才能确认。（两处 trigram 基线分别为 39.5% / 7.5%，模型全部配置仍然没赢。）

## 这个结论也不能推得太远

- 只有 3 个种子，只能说「不显著」，不能说「位置编码没用」。理论上没有位置信号，模型只剩「一袋字」，**这件事没有消失，只是在这个规模下没被测出来**；
- 训练末段 loss 仍有 1.71~1.85，模型远未收敛；一个更受控的设定（同一作品内切分、步数放大、种子 ≥5）才可能测出真实的效应量；
- 因此本文的立场是：**先别把「位置编码当然有用」当成不需要验证的前提**。在这套 5.5 万参数、32 上下文的实验里，它没有兑现出可测量的收益。

**一个必须加的限定（2026-09-14）**：本对照做在 2,401 字与 20,000 字两档。Day-2 的多种子数据显示，**种子噪声随数据量档剧变**——2,000 字档 Top-1 的 σ 是 ±0.2~1.5pt，而 1,000,000 字档只有 **±0.1pt**（1pt 差异 ≈ 10σ）。

也就是说：「差异不超过种子波动」这句话**只在小数据档成立**。到了大数据档，1pt 级的头数差异就是真实的，本实验没有在那个档重跑。

完整数据与边界见 `docs/experiments/2026-09-13-ablation-heads-pos.md`，脚本 `py/ablation.py`。

## 一句话记住

词嵌入回答「这是什么字」，位置嵌入回答「它是第几个字」。两者相加之后，注意力才开始在「排好序的序列」上工作。
