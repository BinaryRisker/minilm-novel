# 文字变成编号：token、词表和陌生字

**系列：从零训练中文小说模型｜第 2 篇（原理篇）**
**前置阅读：原理篇 1；不熟悉的术语可回阅读地图查询**

更新：2026-09-17。本文先讲通用原理，再说明本项目怎样实现；算例均标明用途。

模型不能直接对汉字做矩阵乘法。它先把文字切成小单位，再给每种单位一个编号。这个小单位叫 token，负责转换的工具叫 tokenizer（分词器）。

## 编号不是意思

下面是人为编造的小词表，只用于理解，不能拿这些编号核对真实运行：

| token | 编号 |
|---|---:|
| 未知符号 UNK | 0 |
| 小 | 1 |
| 雨 | 2 |
| 回 | 3 |
| 家 | 4 |

“小雨回家”变成 `[1,2,3,4]`。4 不表示“家”比“雨”重要两倍，编号只是查表地址。换词表后编号可能改变，所以权重和词表必须一起保存。

字符级分词大致逐字符切分，包括汉字、标点和换行。子词分词可以把常见片段合在一起，也会拆开生词。一个 token 既不固定等于一个汉字，也不固定等于一个完整词；文本字数不能直接当作任意模型的 token 数。

## OOV 与 UNK 的区别

OOV 表示“词表里没有”，UNK 是“遇到没有的字符时，用这个统一编号代替”。如果“箱”和“柜”都不在词表里，“打开冰箱”和“打开冰柜”可能被编码成完全相同的序列。模型已经无法从这串编号恢复丢失的区别。

项目一些解码路径把 UNK 显示为空串。屏幕上少了字，不代表模型输入里那个位置消失了；输入中仍可能保留编号 0。观察时要看 token 映射，而不只看解码后的文本。

## 词表怎样建立

分片与历史 sweep 的字符词表统计训练文本的字符频次，使用 `min_freq=3`：出现不足三次的字符转成 UNK；其余按频次及字符排序。`py/train.py` 调用的默认 `min_freq=1`；浏览器的词表策略和早期实验也可能不同，不能把某篇文章的 201、365 或 6379 当成全项目固定词表大小。

只用 train 建词表；val 和 test 用同一张词表编码。这样才能避免根据考试材料调整文字表示。未知率应分别统计，尤其要检查人名和题目中的关键字是否丢失。

## 子词一定更好吗

未必。它可能让常见片段用更少的 token 表示，也可能让罕见汉字拆成更多单位。字节回退改善覆盖，但不保证小说写得好。比较时要报告未知率、同样原文的 token 数、词表参数量和生成质量。

本项目当前主要训练路径仍是字符级，学习版 BPE 不等于已经有正式子词训练流水线。先理解文字有没有完整传进去，再讨论模型是否理解了它。
