========================================================================
外推：这套 JS 代码能不能训大模型
========================================================================

取实测最好利用率 0.47 GFLOPS，外推到 1B 参数模型：

  【小规模预训练】10 亿参数 + 2 亿 token
    总计算量 ≈ 12.0 ×10^18 FLOPs
    浏览器 JS   ≈ 292578 天  (801.6 年)
    RTX 3090    ≈ 33.3 小时
    差距        ≈ 210,656 倍

  【可用级预训练】10 亿参数 + 20 亿 token
    总计算量 ≈ 120.0 ×10^18 FLOPs
    浏览器 JS   ≈ 2925777 天  (8015.8 年)
    RTX 3090    ≈ 333.3 小时
    差距        ≈ 210,656 倍

========================================================================
显存账：1B 参数训练到底要多少内存
========================================================================

  权重 fp16            2.0 GB
  梯度 fp16            2.0 GB
  Adam 一阶动量 fp32   4.0 GB
  Adam 二阶动量 fp32   4.0 GB
  ---------------------------------
  小计（不含激活）      12.0 GB
  + 激活 / 中间张量     ≈ 2~4 GB（视 batch 与 ctx）
  = 至少 14~16 GB 显存

  浏览器现状：单标签页可用 GPU 显存通常 2~6 GB，内存上限约 4 GB。
  结论：连放都放不下，更谈不上训练。
